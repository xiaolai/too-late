## 故事梗概

二〇〇三年除夕夜，东江县一中的工地上死了一个人，埋进了后来的操场底下。纸面上，那一夜「没啥大事」。生不见人，死不见尸；他的妻子守着校门口的包子摊，一年一年寄信，从来不闹。十六年后，扫黑督导组进了县；一场从初三孩子们中间烧起来的祸事，把信访办窗口里一个盖「已办结」章的女人，一步一步拽回了那个除夕夜。

## 作者的话

这是我的第一部中篇小说。

准确地说，它是我第一次正式发表的习作。能独立发表，终究是好的；可局限也正在这里——一切判断的标准、所谓客观的评价，都无从依赖外界，只能自己对自己负责。

创作过程中，我用了大量人工智能辅助。借助它，我可以做格外庞大的案头研究：要弄懂一座县城怎么运转，要弄懂一桩悬而未决的旧案是怎么被一点点办没的，要弄懂护士每天的活计，要还原一座小城十六年的风貌……这些功课，按我这段时间的经验，效率大概是过去没有人工智能辅助时的十倍以上。

人工智能能替我们做很多事。但有两件它做不到：一，它生成不了真正的创意；二，它替不了我们去敲那些本该自己敲下的字。除此之外——它的确是个全知全能、且称职的文字编辑。
